[THE PICKS 시놀로지 업데이트 V22]

수정 내용
- 상단 메뉴의 '포토부스 소개'를 '회사 소개'로 변경
- 회사 소개 옆에 별도의 '포토부스' 메뉴 추가
- 메인 화면의 서비스 소개 버튼을 포토부스 페이지로 연결
- 포토부스 페이지 상단에 세로형 구동 화면 갤러리 추가
- 구동 화면 좌우 이동, 썸네일 선택, 화면 클릭 확대, 확대 화면 좌우 이동 지원
- 관리자에서 구동 화면 이미지를 원하는 만큼 추가·삭제 가능
- AI 콘텐츠 5종 추가: AI 배경 합성 / AI 뷰티필터 / AI 웹툰 / AI 밈 / AI 3D피규어
- 관리자에서 AI 콘텐츠별 사진을 최대 4장까지 추가·삭제 가능
- 맞춤 백월 제작 및 렌탈 갤러리와 관리자 사진 추가·삭제 기능 지원
- 메인 화면 '성공적인 진행 행사' 수치를 1,000+에서 10,000+로 변경
- 포토부스 구동 화면 모니터를 전체 영역 정중앙으로 정렬
- AI 콘텐츠를 화이트 배경 디자인으로 변경
- 콘텐츠 순서를 구동 화면 → AI 콘텐츠 → 맞춤 백월 → 시그니처 포토부스로 변경

중요
- 이번 V22는 기존 홈페이지에 적용하는 업데이트입니다.
- data 폴더와 uploads 폴더는 삭제하거나 덮어쓰지 마세요.
- 관리자 비밀번호, 문의 내역, 기존에 등록한 사진은 그대로 유지됩니다.
- V22 서버가 기존 데이터에 필요한 새 항목을 자동으로 추가합니다.

[V22 적용 방법]

1. V22 ZIP을 컴퓨터에서 압축 해제합니다.
2. File Station → docker → thepicks 폴더를 엽니다.
3. 압축을 푼 파일을 thepicks 폴더에 모두 덮어씁니다.
4. 기존 data와 uploads 폴더는 그대로 둡니다.
5. Container Manager → 프로젝트 → thepicks-homepage로 이동합니다.
6. 오른쪽 위 '중지'를 누르고 완전히 멈출 때까지 기다립니다.
7. 오른쪽 위 '작업'에서 '빌드'를 누르고 Exit Code: 0이 나올 때까지 기다립니다.
8. 약 10초 후 아래 주소를 엽니다.
   http://192.168.0.7:8088/api/version?v=22
9. 응답에서 "version":"22"와 "successful_events":"10000+"가 보이면 정상 적용입니다.
10. 홈페이지를 열고 Ctrl+F5를 누릅니다.

홈페이지: http://192.168.0.7:8088/
관리자: http://192.168.0.7:8088/admin.html
포토부스: http://192.168.0.7:8088/photobooth.html?v=22

외부 주소가 연결된 경우:
https://preview.thepicks.co.kr/photobooth.html?v=22

[관리자 사진 등록]

- 포토부스 콘텐츠 → 구동 화면: 1080×1920 또는 9:16 세로 이미지 권장, 수량 제한 없음
- 포토부스 콘텐츠 → AI 콘텐츠: 정사각형 또는 4:5 이미지 권장, 항목별 최대 4장
- 포토부스 콘텐츠 → 맞춤 백월: 16:10 또는 16:9 가로 이미지 권장, 수량 제한 없음
