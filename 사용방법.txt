[더픽스 홈페이지 관리자 사용방법]

1. START_ADMIN.bat 파일을 더블클릭합니다.
2. 관리자 화면이 자동으로 열립니다.
3. 처음 실행할 때 사용할 관리자 비밀번호를 설정합니다.
4. 메인 화면 / 서비스 소개 / 포토부스 콘텐츠 / 인화 프레임 / 사진·게시글 / 견적 문의 메뉴를 눌러 관리합니다.

- 서비스 소개: 소개 페이지에 표시할 사진 3장을 각각 선택해 저장
- 포토부스 콘텐츠 > 구동 화면: 세로형 화면 이미지를 원하는 만큼 추가·삭제(1080×1920 또는 9:16 권장)
- 포토부스 콘텐츠 > AI 콘텐츠: 5개 항목별 사진을 최대 4장까지 추가·삭제(정사각형 또는 4:5 권장)
- 포토부스 콘텐츠 > 맞춤 백월: 백월 사진을 원하는 만큼 추가·삭제(16:10 또는 16:9 권장)
- 인화 프레임: 베이직·AI 디자인·콜라주 대표사진과 갤러리 관리
- 사진·게시글: 새 글 등록 → 분류 선택 → 제목과 설명 입력 → 사진 선택 → 저장
- 수정: 등록된 글의 수정 버튼을 누른 뒤 내용 또는 사진 변경
- 삭제: 등록된 글의 삭제 버튼 선택
- 견적 문의: 홈페이지에서 접수된 고객 문의 확인 및 상담 완료 표시

홈페이지 주소: http://127.0.0.1:8000/
관리자 주소: http://127.0.0.1:8000/admin.html
포토부스: http://127.0.0.1:8000/photobooth.html?v=22

주의: 검은 서버 창을 닫으면 홈페이지와 관리자 화면이 정지합니다.
실제 인터넷 홈페이지로 운영할 때는 Python 실행이 가능한 웹서버/VPS에 설치해야 합니다.
