Interactive Solution

게임 키오스크

발길을 멈추고 손끝으로 참여하는 최강의 디지털 놀이터

01. 초대형 몰입형 스크린

  • 인간의 시야각에 최적화된 초대형 수직 풀화면 스크린 탑재로 시선 압도
  • 초고감도 멀티 터치 센서 적용으로 남녀노소 누구나 부드럽고 정교한 플레이 가능

02. 체류시간 극대화 효과

  • 단순 영상 및 이미지 송출 기기 대비 압도적인 고객 체류 시간 연장 효과
  • 게임 몰입을 통한 자연스러운 브랜드 각인 및 세일즈 기회 창출

03. 실시간 영수증 연동

  • 게임 종료 시 실시간 즉석 경품 교환권(영수증) 출력 모듈 연동
  • 티켓에 로고 엠블럼 및 바코드를 맞춤 인쇄하여 매끄러운 이벤트 운영과 고객 DB 확보

AI 사주 프로세스

단 3초 만에 완성되는 나만의 트렌디한 운세

01. INPUT

  • 사용자의 이름과 생년월일, 태어난 시간을 화면에 간단하게 터치 입력
  • 남녀노소 누구나 쉽게 이용 가능한 직관적인 UI 제공

02. ANALYSIS

  • 명리학 빅데이터가 탑재된 자체 AI 프로그램의 실시간 정밀 분석
  • 빠른 처리 속도로 대기 인원 없이 원활한 행사 회전율 보장

03. PRINT

  • 행사 맞춤형 커스텀 디자인 프레임에 운세 결과 즉시 출력
  • 영수증 또는 고화질 인화지 형태로 제공하여 만족도 극대화
